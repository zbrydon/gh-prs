# gh-prs

View pull requests you have created:

```sh
gh prs # View pull requests you have created
gh prs --req # View pull requests that have requested your review
gh prs --drafts # View draft pull requests you have created
gh prs --drafts --req # View draft pull requests that have requested your review
```

Install:

```sh
gh extension install zbrydon/gh-prs
```
